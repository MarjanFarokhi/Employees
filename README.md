# Employee Analytics Dashboard

## Overview

This project presents a Power BI dashboard for analyzing employee and workforce data across different departments and countries.

The dashboard provides an overview of workforce size, salary, gender distribution, overtime, leave records, department performance, and employee experience.

## Dataset

The dataset was provided in Excel format and contains employee-related data.

## Tools

- Microsoft Excel
- Microsoft Power BI

## Dashboard

The Excel dataset was imported into Power BI and used to create an interactive dashboard for analyzing workforce information and comparing employee-related metrics across departments and countries.

## Key Analysis

- Total number of departments
- Number of countries in which the company operates
- Total number of employees
- Average annual salary
- Gender distribution
- Overtime hours by gender
- Percentage of employees working overtime by gender
- Sick leave by gender
- Unpaid leave by gender
- Percentage of employees taking sick leave and unpaid leave
- Top 5 departments based on total salary
- Salary distribution and percentage across departments
- Total salary comparison across countries by gender
- Comparison of the top 10 departments by employee count, segmented by gender
- Comparison of employee experience across countries by gender

## Workforce Analysis

The dashboard provides insights into workforce composition, salary distribution, overtime, leave patterns, department size, employee experience, and differences between male and female employees across departments and countries.

## Business Insights

The dashboard helps identify workforce patterns and differences in salary, overtime, leave, department size, and employee experience. These insights can support HR-related analysis and workforce planning.
